# 앱 모드 사용 가이드 (v0.7.0)

> 선택한 앱을 **가상 디스플레이**에서 띄워 테슬라/노트북 브라우저로 미러링합니다.  
> 전체화면 모드(부모님용)와 **전송 경로 동일**: Cloudflare Worker + WebRTC JPEG + 인터넷 ICE(STUN).

## 전체화면 vs 앱 모드

| | 전체화면 | 앱 모드 |
|--|----------|---------|
| 캡처 | 폰 화면 그대로 (MediaProjection) | scrcpy 가상 디스플레이 |
| ADB / 무선 디버깅 | 불필요 | **필요** (최초 1회 페어링) |
| 폰 사용 | 미러링 중 폰 화면 = 차 화면 | 폰은 자유롭게, 차에는 가상 화면 |
| 해상도 | 폰 해상도 | 기본 1280×800 또는 테슬라 비율 맞춤 |
| 권장 사용자 | 부모님 / 단순 미러링 | 내비 전용 헤드리스 |

**부모님은 전체화면만 쓰면 됩니다.** 앱 모드 UI는 선택하지 않으면 동작에 영향 없습니다.

## 사전 준비

1. 공용 워커 URL 시크릿 저장 (전체화면과 동일)
2. **무선 디버깅** ON (설정 → 개발자 옵션)
3. 최초 1회 ADB 페어링 (아래)

### 무선 디버깅 페어링 (최초 1회)

1. 앱 모드 → **「무선 디버깅 설정 열기」** (가능하면 분할 화면)
2. 무선 디버깅 ON → **페어링 코드로 기기 페어링**
3. 그때 보이는 **포트 + 6자리 코드**를 앱에 입력 → 페어링  
4. 이후에는 코드 재입력 불필요. 평소 **무선 디버깅만 켜 두면** 앱이 자동 연결 시도.

> 페어링 창을 다시 열면 숫자가 바뀌는 것은 정상입니다.  
> **이미 페어링된 뒤에는 그 숫자를 다시 넣을 필요 없습니다.**

## 사용 순서

1. 폰: TeslaMirror → **앱 모드**
2. (연결됨 확인) → **앱 캐스트 시작**
3. 테슬라/노트북 브라우저: 워커 URL 북마크 접속
4. 가상 홈(런처)에서 T맵/카카오맵 등 실행

인터넷 ICE ON이면 핫스팟 없이 집 Wi‑Fi만으로도 노트북 테스트 가능.  
테슬라는 LAN 격리 때문에 **공개 워커 + 인터넷 ICE** 가 기본 경로.

## 옵션: 테슬라 화면 꽉 채우기 (기본 ON)

- **ON**: 뷰어 창 비율을 기억 → **다음 캐스트부터** 가상 디스플레이 비율 맞춤 + 뷰어가 화면 전체 표시
- **OFF**: 고정 1280×800
- **학습 비율 초기화**: 잘못 학습된 값 삭제

뷰어 비율 학습을 위해 `cloudflare/worker.js` 최신 배포가 필요합니다.

## 파이 제스처 (앱 화면 안에서)

런처(홈)에서는 파이 없음. **맵 등 앱 실행 후**:

1. 화면 **가장자리**를 **2초 이상** 꾹
2. 드래그로 선택  
   - **Back** (왼쪽)  
   - **Home** (위) → 런처로 복귀  
   - **Cancel** (아래/가운데)

살짝 탭은 앱 터치로 전달됩니다.

## 연결이 「연결 중…」에 멈추면

뷰어가 약 8초 후 자동 재시도합니다.  
브라우저를 껐다 켜도 자동 재연결을 시도합니다.  
수동 새로고침도 유효합니다.

## Cloudflare Worker

- 파일: `cloudflare/worker.js`
- 뷰어·시그널링 공용 (전체화면·앱 모드 동일 URL)
- 대시보드에 붙여넣기 후 Deploy

## 개발 메모

| 구성 | 파일 |
|------|------|
| FGS | `AppCastService.kt` |
| 해상도/꽉채우기 | `AppCastDisplayPrefs.kt` |
| 런처 홈 | `AppLauncherActivity.kt` |
| scrcpy | `scrcpy/ScrcpyController.kt` |
| WebRTC (앱) | `webrtc/AppWebRtcSession.kt` |
| WebRTC (전체화면) | `webrtc/WebRtcSession.kt` |
| 뷰어 | `cloudflare/worker.js` |

- WebRTC `dispose()` 호출 금지 (close만) — 기기별 크래시
- `vd_system_decorations=false` — 가상 디스플레이 시스템 바 제거
- AppLauncher `exported=true` — shell `am start --display` 용 (Android 16)

자세한 과거 인계·미완 설계: `docs/app-mode-handoff.md` (상당 부분 구현 완료, 본 문서 우선).
